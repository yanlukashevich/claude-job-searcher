# Portal quirks — justjoin.it and pracuj.pl own forms

Read this **only** when Apply opened the portal's own form and did **not** hand you off to a
company ATS (`applier_instructions.md` §3). Read your portal's section, ignore the other.

---

## justjoin.it — internal modal

The **Apply button submits immediately; it does not open a form to fill.** The fillable form is
behind the **"edit"** link on the CV box. Go there *first*, swap the pre-attached CV for the
variant chosen in §7, confirm the new filename shows, write the message per §6, and only then
Apply.

Personal fields the account pre-filled: check them against `profile.md`, leave them if they match.

## pracuj.pl — quick-apply widget

Same shape, different labels. Here the pre-attached CV also comes with a **generic boilerplate
message already in the message box — replace it** (§6), never send it.

1. Open the form with the **pencil** icon on the CV box.
2. Swap the attachment with **"zmień lub odrzuć plik"**; confirm the new filename shows.
3. Submit is **"Wyślij formularz"**.

Apply may instead run an intermediate **"Kontynuuj aplikowanie"** step, or hand off to the
employer via **"Aplikuj na stronie pracodawcy"** — that one reuses the same tab and puts you on
an external ATS, so read `ats_quirks.md` instead (playbook §3).
